# Yogita Birthday Website 🎂❤️

A simple romantic birthday surprise website made for Yogita.

## Files
- `index.html` — Main webpage
- `style.css` — Website design and animations
- `script.js` — Buttons, music and floating animations
- `song.mp3` — Optional background music

## How to Use
1. Put all files in the same folder.
2. Add your own `song.mp3` to the folder.
3. Open `index.html` in a browser.
4. Press **Open Your Surprise 💝**.
5. Use the **Music On/Off** button to control the song.

## Folder Structure
Yogita_Birthday_Website/

## Note
Use an audio file that you have permission to use.
